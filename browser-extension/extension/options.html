DaiDocs capture

Settings live in the on-page pill now. Click the gear on the DaiDocs pill (top-left of any supported site), open More settings, and control everything there. This page is only needed to grant the "all websites" browser permission, and to bring the pill back if you have hidden it, since a page cannot do those two things for itself.

The extension sends captures to the DaiDocs capture server on this machine. Start it with npm run capture in the DaiDocs folder. Your captured data stays on your computer.

What gets captured

AI chats are captured as plain text into your memory store. Browsing (X and websites) always goes to the encrypted Vault, in its own folder, separate from chat history.

"All websites" asks the browser for permission to run on every site. Chat sites and X keep their own toggles above. A site can also be toggled from the on-page pill.

Vault

The Vault stores your browsing history encrypted on disk. An assistant can only read it after you give it the vault password (node vault.mjs unlock). Set it up once with node vault.mjs init --password ... in the DaiDocs folder.

Checking vault...

Off by default. When on, chats are stored encrypted too and are not converted to searchable memory until you unlock and export them.

Server

Default 41100. Must match DAIDOCS_CAPTURE_PORT if you set it.
